# Agent Code Craft

Curated engineering skills for AI coding agents — principles, patterns, and executable examples that make agent-written code production-grade.

## Skills

- **properties-of-good-tests** — The 9 properties every test should have (Beck, Fowler, Meszaros, Feathers)
- **hexagonal-architecture-enforcement** — Ports & adapters boundaries enforced by lint or the compiler, never by convention. Validated configs for TypeScript, Python, Go, Java, C# and Rust — each run against a working fixture, clean and with seeded violations.
